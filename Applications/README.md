# Applications

Datto RMM **deployment** components — the ones whose job is to install a
product.

Named for the product and nothing else: `Adobe Acrobat Reader [Win]`, not
`Install Adobe Reader [Win]`. The category already says it deploys something,
and a version number in the name goes stale the first time the component is
updated in place.

One folder per component. See [`../CONTRIBUTING.md`](../CONTRIBUTING.md).

Empty means nothing has been created or changed here since the rule took
effect — not that we have no deployment components. Datto is authoritative for
what exists.
